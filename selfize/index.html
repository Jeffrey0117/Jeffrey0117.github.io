自架的 SQLite 後端 · 像 PocketBase，但是 Node.js

寫一個 JSON，
就有一整組 API。

做小產品時，後端常常只是要存幾張表、讓前端讀寫。Selfize 讓你用一段 JSON 定義資料表，馬上就有新增、查詢、修改、刪除的 REST API。不用寫 migration，不用 ORM，資料全部在一個 SQLite 檔裡。

它做什麼

一般要自己寫一個後端才有的東西，這裡用設定就拿到。

執行中開新資料表

打一個 API 帶上名稱和欄位，Selfize 就在 SQLite 裡建一張真的資料表。不用重啟、不用寫 migration。

POST /api/collections

每張表自動有 CRUD

列表、單筆、新增、修改、刪除五個端點自動就有。每筆紀錄自動帶 UUID 和建立、更新時間。

/records

用網址查詢

篩選有 7 種運算（等於、大於、LIKE 等），可以多欄位排序、分頁、只挑幾個欄位回傳。一頁最多 500 筆。

?price=gt.100

關聯一次帶回來

欄位標上 ref 指向另一張表，查詢時加 expand，對方那筆就直接附在結果裡，不用再打第二次。

?expand=owner_id

讀寫各自設權限

每張表的讀、新增、修改、刪除，各自設成公開、只限管理者，或只限登入的使用者。

public · admin · user

每個人只碰得到自己的

設成 user 的表，伺服器會在每筆資料蓋上擁有者，查詢時強制過濾。別人的紀錄一律回 404，前端想偷看也看不到。

_owner

從空資料庫到前端能用

中間沒有一行後端程式碼要你寫。

  1. 啟動伺服器第一次跑會自己建出 data/selfize.db，開好 WAL 模式，和一張記錄所有 collection 定義的表。
  2. 定義一個 collection送出名稱、欄位和權限。名稱只能小寫英數加底線、不能用底線開頭；有用到 user 權限卻沒宣告 _owner 欄位，會自動幫你補上。
  3. Selfize 建表每個欄位依型別對應到 SQLite 欄位，再加上 id、created_at、updated_at。
  4. 前端直接讀寫每個請求進來先看這張表的權限：公開就放行，管理者要帶 token，user 要帶 LetMeUse 登入 token（ES256 簽章，伺服器用公開金鑰驗）。
  5. 要加欄位就 PATCH新欄位會用 ALTER TABLE 加上去，舊資料不動。只能加，不會幫你刪欄位或改名。
  6. 備份就是複製一個檔所有 collection 和資料都在同一個 SQLite 檔裡，複製它就備份完了。

怎麼開始

四行指令跑起來，再用一個 curl 開第一張表。

git clone https://github.com/Jeffrey0117/Selfize.git
cd Selfize
npm install
SELFIZE_TOKEN=換成你自己的長字串 npm start

# 開一張 books 表：任何人可讀，只有管理者能改
curl -X POST localhost:4021/api/collections \
  -H "Authorization: Bearer $SELFIZE_TOKEN" \
  -H "content-type: application/json" \
  -d '{"name":"books",
       "schema":[{"name":"title","type":"text","required":true},
                 {"name":"price","type":"number"},
                 {"name":"tags","type":"json"}],
       "rules":{"create":"admin","update":"admin","delete":"admin"}}'

# 查詢：價格大於 100、新的在前、只要書名
curl "localhost:4021/api/collections/books/records?price=gt.100&sort=-created_at&select=title"

# { "items": [ { "id": "…", "title": "…" } ],
#   "total": 1, "limit": 100, "offset": 0 }

沒設 SELFIZE_TOKEN 會用程式裡的預設開發用 token，放上網路前一定要換掉。

rules 沒寫的動作預設是 public，所以上面的例子讀取不用帶 token。

用瀏覽器打開伺服器根目錄就是管理後台：輸入 token 後可以建表、刪表，用表格瀏覽、新增、編輯紀錄。

開發時用 npm run dev，改了程式會自動重啟。其他設定只有 PORT、CORS_ORIGIN，和 user 權限要用的 LetMeUse 來源與允許的 app 白名單。
