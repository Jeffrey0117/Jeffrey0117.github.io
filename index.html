一個人的自架生態系

自己會用的東西，
就自己做出來。

語音輸入、金流、雲端硬碟、資料庫和部署平台，全部自己寫、自己架、每天自己用。這裡每個專案都有一頁，講清楚它解決什麼問題、怎麼運作。

給所有人用

桌面 App · 開源 SpeakSlow 聲聲慢 專為中文打造的本地語音輸入。講完直接貼到游標處，不上雲。 桌面 App · 開源 ReVid 看影片學語言。自動上字幕、點字查單字、章節標記，手機也能連進來看。 桌面 App · 開源 RePic 快到不像話的 Windows 看圖程式。虛擬相簿不佔空間，網路圖片也能收。 桌面 App · 開源 DuckShot 截圖鴨鴨 免費 Windows 截圖工具。區域／全螢幕／視窗，內建文字辨識，一鍵上傳分享。 自架服務 · 開源 Pokkit 自己的雲端硬碟。大檔分享、密碼與到期時間、在家高速上傳。

金流

後端服務 PayGate 所有產品共用的收銀台。結帳、續訂、到期降級、通知產品。 npm 套件 · 開源 newebpay-kit 藍新金流零依賴 Node SDK，含信用卡定期定額。

資料與基礎設施

自架服務 · 開源 Selfize 自架的 SQLite REST API，動態建表，像 PocketBase 但用 Node.js。 自架服務 · 開源 SelfBase PostgreSQL 一鍵備份、還原、清舊檔，加上 Redis 健康檢查。

更多專案陸續補上。完整清單在 GitHub。
